本次新增在線支付展示配置：列表新增「配置類型」欄；新增彈窗新增「配置類型」單選（充值｜活動）與活動分支欄位。前台充值頁：新增兌換碼入口，點擊後於充值頁下方區塊展示既有兌換功能。

本次刪除無。

2. 需求目的

前台充值頁新增「兌換碼」入口，讓用戶在充值頁內即可使用既有的兌換碼功能。

  • 入口於後台「在線支付展示配置」設置：設置即展示、不設置即不展示，與既有充值入口的配置動線一致。
  • 兌換功能本身（兌換碼活動的配置、兌換規則、提示文案）全部沿用既有「兌換碼活動」功能，不做任何異動；本次僅在充值頁多一個展示與操作的地方。

3.4 操作注意事項（不做系統判斷）

  • 活動類型「兌換碼」可建立多筆，建立幾筆、前台充值頁就出現幾個兌換碼入口——系統不限制、不提醒，操作人自行注意配置數量。

4. 前台改動｜充值頁兌換碼入口

以 OKBET Web 為示範；各平台（WOWGame／OKBET／123GO，PC／H5／APP）功能與判斷相同，畫面由 UI 依各端樣式出圖。

4.1 入口

  • 後台建立兌換碼設置後，充值頁的支付方式入口區塊即多出一個兌換碼入口。
  • 入口圖＝該筆設置的「渠道圖示（日间／夜间）」（前台僅展示圖片）；排序＝該筆「排序」；分頁歸屬勾選僅 WOWGame 生效，勾選後才會出現在指定分頁（既有規則）。

4.2 點擊入口後的展示

  • 點擊兌換碼入口後，不跳出彈窗，而是於充值頁下方區塊展示兌換功能（取代原本點擊充值入口後顯示的支付內容區塊）。
  • 區塊內容＝既有兌換功能的「兌換」內容（兌換碼輸入與提交），功能與既有兌換碼頁面的兌換完全相同；僅放兌換、無 tab，不含兌換記錄。
  • 點回其他充值入口時，下方區塊恢復為該入口對應的支付內容。

4.3 兌換操作與提示

  • 兌換操作、成功／失敗等後續跳出的提示彈窗，全部與既有兌換碼頁面相同。兌換碼各情況／各兌換獎品的提示彈窗均使用既有的，此處不全部列舉，僅以失敗、成功各一為示意。
  • 不論兌換成功或失敗，提示彈窗關閉後均停留在當前充值頁面。
  • 提示彈窗內原本就有跳轉設定的按鈕（如兌換成功彈窗的「立即使用」），行為不異動、照既有設定跳轉。

5. 顯示判斷

  • 充值頁的兌換碼入口僅判斷後台「在線支付展示配置」是否已建立設置：已建立＝顯示、未建立＝不顯示。
  • 與充值側的渠道／商戶三態層級判斷（正常／維護／停用）完全無關：不吃任何渠道或商戶狀態，也沒有「入口顯示維護」的情境（本頁設置本身無狀態欄位）。
  • 兌換碼既有的其他入口不受本頁設置影響，照既有邏輯顯示與使用、不異動——未建立本設置僅代表充值頁不顯示兌換碼入口，不影響其他入口使用兌換功能。
  • 兌換功能本身的所有規則（有效期、可領取次數、參與條件等）均吃既有「兌換碼活動」設定，本次不異動。
